简介：
相比于其他现代编程语言，C语言标准库可用的功能非常有限，这使得开发过程缓慢且低效。为了解决这些问题，开发者常常会引入Glib、Apache APR等重量级库，但由于他们类型繁琐，体积过重等问题导致很多场景下并不适用。这个库是对标准库的补充不依赖任何第三方程序接口，它提供了开发人员期待的大部分基本工具，但避免实现SSL/HTTP/ZIP等高级的功能，因为额外专门的库可以做的更好，同时也能保持轻量级。工程通过Autotools管理以实现可靠的多平台兼容性，还可以通过设置编译选项对功能进行精细的裁减以适应嵌入式环境。

特点：
工具全面：基本功能覆盖全面，容器和算法可以很好满足开发对基本工具的需求
兼容性强：基于C99开发，多种平台和架构之间的高度可移植，Windows、Linux、FreeBSD、OpenBSD、Android等操作系统，主流硬件全面兼容
高可靠性：测试用例覆盖全面
接口设计：使用侵入式容器，爆露细节以支持扩展原有功能，同时尽可能避免容器内的内存分配

功能：
基本功能：系统和架构探测、编译器特性、字节序列探测和转换
容器和算法：单链表、双链表、散列表、跳表、堆、伸展树、索引、双端队列、多层自动机、ID分配器、环形缓冲区、位图、伪随机数
散列函数：crc校验、Thomas Wang 整数散列和逆运算、Murmur2、Lookup3，以上算法均支持32位和64位版本）
字符串操作：跨平台字符串、重写的printf系列函数、完整UNICODE支持、编码转换（GBK、EUC-KR、Big5、Shift-jIS等）、绳索容器、字符串缓冲
内存分配器：内存集合、Slab固定内存分配器、线性分配器
多线程：线程、互斥量、条件变量、读写锁、线程本地存储、一次初始化、线程池、Future/Promise模型
平台能力：进程执行（读写标准IO）、动态库加载、路径操作、时间计算
交互：信号处理、终端颜色控制、行编辑器、命令行参数解析
网络操作：Reactor模型、本地通信、异步套接字、异步DNS
基础密码学：AES算法、SHA256摘要算法、MD5摘要算法、随机数
数据表示：Json操作、Json路径搜索、Base64编解码、Ini配置文件
调试和错误处理：单元测试、错误代码、断言、堆栈跟踪、输出转储、各种容器的Sanitizer、日志
