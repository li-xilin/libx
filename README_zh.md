# LIBX -轻量级 C 扩展库

[[English](./README.md)]

## 简介

与其他现代编程语言相比，C 语言标准库提供的功能较为有限，开发过程难免缓慢低效。开发者常通过引入 Glib、Apache APR 等重量级库来弥补不足，但这些库类型繁琐、体积庞大，在很多场景下并不适用。

本项目是对 C 标准库的补充，不依赖任何第三方程序接口，提供开发者在日常开发中期待的大部分基础工具，同时避免实现 SSL、HTTP、ZIP 等高级功能。这些高级功能由专门库实现会更好，也有助于保持本库的轻量级特性。

## 特点

- **工具全面**：覆盖常用基础功能，容器与算法可满足大多数开发场景。
- **兼容性强**：基于 C99 开发，兼容 Windows、GNU/Linux、FreeBSD、OpenBSD、Android、OSX 等操作系统及主流硬件。
- **高可靠性**：测试用例覆盖全面，保障库的稳定可靠。
- **接口设计**：采用侵入式容器，便于扩展功能，并尽量减少容器内部的内存分配。

## 构建

项目使用 Autotools 管理构建，具备良好的多平台兼容性。

```sh
$ cd libx
$ autoreconf -fiv
$ ./configure
$ make
```

可通过编译选项精细裁剪功能，适应嵌入式等资源受限环境。

## 功能

### 基础能力

- 平台和架构探测
- 编译器特性检测
- 字节序列探测与转换

### 容器与算法

- 单/双链表
- 动态数组
- 散列表
- 跳表
- 堆（优先队列）
- 伸展树
- 索引
- 双端队列
- 分层有限状态自动机
- ID 分配器
- 环形缓冲区
- 位图操作
- MT19937 伪随机数生成

### 哈希函数

- CRC 校验（32 位 / 64 位）
- Thomas Wang 整数散列及其逆运算（32 位 / 64 位）
- Murmur2（32 位 / 64 位）
- Lookup3（32 位 / 64 位）

### 字符串操作

- 跨平台字符串
- 重写的 printf 系列函数
- 完整 Unicode 支持
- 编码转换（GBK、EUC-KR、Big5、Shift-JIS 等）
- 绳索容器
- 字符串缓冲

### 内存分配器

- 内存集合
- Slab 固定内存分配器
- 线性分配器

### 多线程

- 线程
- 互斥量
- 条件变量
- 读写锁
- 线程本地存储
- 一次初始化
- 线程池
- Future/Promise 模型

### 平台能力

- 进程执行（支持标准 I/O 读写）
- 动态库加载
- 路径操作
- 时间计算

### 交互

- 信号处理
- 终端颜色控制
- 行编辑器
- 命令行参数解析

### 网络操作

- Reactor 事件模型（支持 poll 和 epoll）
- 本地 IPC 通信
- 异步套接字
- 异步 DNS

### 基础密码学

- AES 算法
- SHA-256 摘要算法
- MD5 摘要算法
- 安全随机数生成

### 数据表示

- JSON 操作
- JSON 路径搜索
- Base64 编解码
- INI 配置文件
- UUID 生成与解析（支持 v1、v4、v7）

### 调试与错误处理

- 单元测试
- 错误处理
- 静态断言与动态断言
- 堆栈跟踪
- 结构化转储
- 日志
