# libx - 轻量级 C 扩展库

## 简介

与其他现代编程语言相比，C 语言标准库提供的功能较为有限，开发过程难免缓慢低效。开发者常通过引入 Glib、Apache APR 等重量级库来弥补不足，但这些库类型繁琐、体积庞大，在很多场景下并不适用。

本项目是对 C 标准库的补充，不依赖任何第三方程序接口，提供开发者在日常开发中期待的大部分基础工具，同时避免实现 SSL、HTTP、ZIP 等高级功能。这些高级功能由专门库实现会更好，也有助于保持本库的轻量级特性。

## 特点

- **工具全面**：基础功能覆盖全面，容器与算法可满足大多数开发场景对基础工具的需求。
- **兼容性强**：基于 C99 开发，在 Windows、Linux、FreeBSD、OpenBSD、Android 等操作系统及主流硬件平台上具备高度可移植性。
- **高可靠性**：测试用例覆盖全面，保障库的稳定可靠。
- **接口设计**：采用侵入式容器，暴露实现细节以支持扩展原有功能，同时尽量避免容器内部的内存分配。

## 构建与定制

项目使用 Autotools 管理构建，具备可靠的多平台兼容性。

```
$ cd libx
$ autoreconf -fiv
$ ./configure
$ make
```

通过设置编译选项，可对功能进行精细裁剪，以适应嵌入式等资源受限环境。

## 功能

### 基本功能

- 系统和架构探测
- 编译器特性探测
- 字节序列探测与转换

### 容器与算法

- 单链表、双链表
- 散列表
- 跳表
- 堆
- 伸展树
- 索引
- 双端队列
- 多层自动机
- ID 分配器
- 环形缓冲区
- 位图操作
- 伪随机数生成

### 哈希函数

- CRC 校验，支持32位和64位
- Thomas Wang 整数散列及其逆运算，支持32位和64位
- Murmur2，支持32位和64位
- Lookup3，支持32位和64位

### 字符串操作

- 跨平台字符串
- 重写的 printf 系列函数
- 完整 Unicode 支持
- 编码转换（GBK、EUC-KR、Big5、Shift-JIS 等）
- 绳索容器
- 字符串缓冲

### 内存分配器

- 内存集合
- Slab 固定内存分配器
- 线性分配器

### 多线程

- 线程
- 互斥量
- 条件变量
- 读写锁
- 线程本地存储
- 一次初始化
- 线程池
- Future/Promise 模型

### 平台能力

- 进程执行（读写标准 I/O）
- 动态库加载
- 路径操作
- 时间计算

### 交互

- 信号处理
- 终端颜色控制
- 行编辑器
- 命令行参数解析

### 网络操作

- Reactor 事件模型（支持poll和epoll）
- 本地IPC通信
- 异步套接字
- 异步 DNS

### 基础密码学

- AES 算法
- SHA-256 摘要算法
- MD5 摘要算法
- 随机数

### 数据表示

- JSON 操作
- JSON 路径搜索
- Base64 编解码
- INI 配置文件
- UUID生成和解析（支持生成v1、v4、v7）

### 调试与错误处理

- 单元测试
- 错误代码
- 断言
- 堆栈跟踪
- 输出转储
- 各种容器的 Sanitizer
- 日志

也可以通过查看 [HEADERS.md](https://github.com/li-xilin/libx/HEADER_zh.md) 了解各个头文件的详细描述。
